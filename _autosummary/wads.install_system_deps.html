wads.install_system_deps¶

Install system dependencies from [tool.wads.ops.*] sections in pyproject.toml.

This script reads system dependency configurations and installs them on the appropriate platform. It can be used as a standalone CLI tool or imported as a module.

Each [tool.wads.ops.<dep>] section may declare an install_timeout (seconds) to raise the per-command ceiling for a dependency that is slow but healthy — a cold-cache apt-get install ffmpeg on a GitHub runner is the motivating case. Without a declaration the timeout stays at DFLT_INSTALL_TIMEOUT:

[tool.wads.ops.ffmpeg]
install_timeout = 900
install.linux = ["sudo apt-get update", "sudo apt-get install -y ffmpeg"]

The CLI’s --install-timeout sets the fallback for dependencies that declare none; a declaration always wins over it.

A failed or timed-out install command is retried with exponential backoff (DFLT_INSTALL_RETRIES extra attempts, DFLT_INSTALL_BACKOFF seconds before the first retry, doubling), because the usual cause on a hosted runner is a transient apt mirror timeout that a raised ceiling does not cure. A dependency may declare install_retries (0 disables retrying); the CLI’s --install-retries sets the fallback. Worst case for a command that always fails is (retries + 1) * install_timeout plus the backoff waits. Commands are retried one at a time, so a successful apt-get update is not repeated when only the following install flaked.

An install command may name a wads recipe instead of spelling it out (issue #160):

[tool.wads.ops.ffmpeg]
check.linux = "ffmpeg -version && ffprobe -version"
install.linux = "wads:static-ffmpeg"

expands to static_ffmpeg_commands(): a pinned, sha256-checked static build in seconds instead of a crawling apt mirror, with apt as the fallback (Linux x86_64 only; another architecture goes straight to apt). Override its parameters (url, sha256, …) under [tool.wads.ops.ffmpeg.recipe]; an unknown or mistyped parameter fails the dependency. Running the binaries in the check (rather than which) also catches a wrong-architecture or corrupt download.

An install whose commands all exit 0 is not trusted on that alone: when the dependency declares a check.<platform>, that check is re-run afterwards, and a dependency whose check still fails is re-installed (DFLT_VERIFY_RETRIES more rounds, each after a backoff wait that starts at DFLT_INSTALL_BACKOFF seconds and doubles) and then reported as failed. Package managers do report success for installs that did nothing — Chocolatey prints installed 0/0 packages and exits 0 when its feed returns a 5xx — and a CI job would then run its tests without the dependency, red for the wrong reason or green with the coverage silently skipped (issue #162). A dependency whose check cannot pass in the installing process (one that only works in a new shell, say) opts out with verify_install = false. A blank check counts as no check: not verified.

So the worst case for one dependency is (verify_retries + 1) full install rounds — each up to n_commands * (retries + 1) * install_timeout plus its command backoffs, followed by its checks (n_checks * DFLT_CHECK_TIMEOUT) — plus the backoff waits between rounds: with the defaults, a failing verify roughly doubles the install time.

check and install take a string or a list. A list item is either a command line or a command in argv form (a list of strings, e.g. check.linux = [["dpkg", "-s", "unixodbc"], ["rpm", "-q", "unixODBC"]]), which is quoted into one command line for the platform’s shell. Checks are OR-ed (any passing one means installed); install commands are AND-ed (run in order, all must succeed).

Module Attributes

SLOW_DEP_INSTALL_TIMEOUTS

Dependencies with a big dependency tree get a longer ceiling than the global default (a cold-cache apt-get install ffmpeg outlasts 300s).

RECIPE_PREFIX

An install command of the form wads:<name> names a recipe here, expanded into the commands the recipe builds from its defaults overridden by the dependency's [tool.wads.ops.<dep>.recipe] table (issue #160).

STATIC_FFMPEG_DEFAULTS

Static ffmpeg + ffprobe for linux64 (x86_64), checked against its sha256.

DFLT_APT_LOCK_TIMEOUT

Seconds apt waits for the dpkg lock before giving up (-o DPkg::Lock::Timeout).

DFLT_KILL_GRACE

Seconds between SIGTERM and SIGKILL when a timed-out install is stopped.

DFLT_VERIFY_RETRIES

Extra install rounds for a dependency whose commands succeeded but whose declared check still fails afterwards (a package manager that reported success for nothing — e.g. Chocolatey on a feed 5xx).

UNIX_ONLY_CHECK_COMMANDS

Commands a check.windows cannot rely on, with what to use instead.

INSTALL_RECIPES

Recipes install.<platform> = "wads:<name>" may name; extend by adding to it.

Install a dependency, then confirm it with its check commands.

install runs install_cmds (with its own per-command retries); when it reports success and check_cmds declares a command, is_installed must agree, or the install is repeated up to verify_retries more times, after backoff seconds (doubling), before failing. With no check declared the install’s own exit status is all there is to go on. backoff and sleep are also passed on to install for its per-command retries.

Returns (success, error_message) like install_dependency().

wads.install_system_deps.static_ffmpeg_commands(params)[source]¶

Commands installing a static ffmpeg build: download, verify, extract, else apt.

A static build takes seconds; apt-get install ffmpeg pulls ~99 packages from a runner mirror that sometimes crawls for 20+ minutes, which no timeout or retry cures (issue #160). params overrides STATIC_FFMPEG_DEFAULTS: url and sha256 of a .tar.xz whose */bin/ holds binaries, extracted into bin_dir. The archive goes to $RUNNER_TEMP (else /tmp) and is removed afterwards, whatever happened. On a machine that is not x86_64, or when the download, the checksum or the extraction fails, the command fails, or, when apt_fallback is true, removes any partly extracted binaries and installs ffmpeg from apt (--no-install-recommends) with a warning.

>>> [cmd] = static_ffmpeg_commands({"apt_fallback": False})
>>> "sha256sum -c -" in cmd and "'*/bin/ffprobe'" in cmd and "apt-get" not in cmd
True
Return type:

List[str]

wads.install_system_deps.unix_only_check_warnings(ops)[source]¶

Warnings for check.windows commands that call a Unix-only command.

ops is the [tool.wads.ops] table (anything else declares nothing); the commands and their suggested replacements are UNIX_ONLY_CHECK_COMMANDS. The commands are reported, not rewritten: they are the user’s.

>>> unix_only_check_warnings({"ffmpeg": {"check": {"windows": "which ffmpeg"}}})
['check.windows for ffmpeg uses `which`, which cmd.exe lacks; use `where <name>` or `<name> -version` (`which ffmpeg`)']
>>> unix_only_check_warnings({"ffmpeg": {"check": {"windows": "where ffmpeg", "linux": "which ffmpeg"}}})
[]
Return type:

List[str]
