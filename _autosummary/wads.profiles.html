wads.profiles¶

Declarative generation profiles and overlays built on the engine.

A profile is a named declarative description of a project setup expressed as a list of wads.templating.Artifact. The default profile (python-lib) is produced by wads.populate.

This module hosts two opt-in overlays added on top of an existing project:

  • The frontend profile registry (issue #39): a small registry of language/toolchain profiles – js (the original #32 overlay, the back-compat anchor), ts (single-package TypeScript), and ts-monorepo (pnpm workspaces + turbo). A project may declare several frontend components (e.g. js and ts); each lives in its own subdir with its own path-filtered workflow, so they never collide. Selected via populate --frontend <profile>[,<profile>] (--with-npm stays as an alias for --frontend js). Profiles are extensible through register_frontend_profile().

  • The tests-folder overlay (issue #4): scaffolds a tests/ package.

  • The native-core registry (issue #214): a Rust core built by maturin behind a Python facade (populate --native maturin); see apply_native().

Nothing here runs by default; the Python populate path and the name/name/ root layout are untouched.

class wads.profiles.NativeProfile(name, template_dir, pyproject_fragment, replaces=(), drops=(), facade='', new_package_only=(), gitignore_patterns=(), lockfile='', lockfile_command=(), lockfile_env=(), missing_toolchain=(), toolchain_pin=(), toolchain_list=(), unlicensed=(), description='')[source]¶

Bases: object

A native (compiled-extension) backend that populate --native can scaffold.

Paths are template paths (with the tokens); pyproject tables are dotted ("tool.hatch").

Parameters:

  • name (str) – registry key; also the backend name wads.native_build knows.

  • template_dir (str) – folder of files written at their (token-substituted) paths.

  • pyproject_fragment (str) – TOML file of the pyproject tables the backend needs.

  • replaces (tuple) – fragment tables that replace the pyproject’s whole (rather than merge into it), e.g. "build-system".

  • drops (tuple) – tables a NEW pyproject loses, because they configure what replaces replaced (e.g. "tool.hatch"); an existing one is told to.

  • facade (str) – the package’s __init__.py template. A missing or blank one is written; a real one is kept and the lines the template tests need are reported.

  • new_package_only (tuple) – files written only when the package is new (no real facade).

  • gitignore_patterns (tuple) – .gitignore entries the layout relies on.

  • lockfile (str) – lockfile the build needs (--locked), generated when missing.

  • lockfile_command (tuple) – command generating lockfile, run in the project root.

  • lockfile_env (tuple) – (name, value) pairs added to that command’s environment.

  • missing_toolchain (tuple) – (marker, command): when the lockfile command’s stderr has marker, the pinned toolchain is missing and command installs it.

  • toolchain_pin (tuple) – (file, table, key) naming the pinned toolchain channel (checked against toolchain_list before the lockfile command runs).

  • toolchain_list (tuple) – command listing the installed toolchains, one per line.

  • unlicensed (tuple) – (text, replacement) pairs applied to the templates when the package’s licence cannot be determined (the crates then declare none).

  • description (str) – one-line human summary.

wads.profiles.apply_frontend(pkg_dir, *, profile='js', project_name, description='', license=None, subdir=None, package_name=None, version='0.0.1', package_manager=None, workspace_glob='packages/*', example_package_name=None, watch_paths=None, overwrite=(), on_add=None, on_skip=None)[source]¶

Apply one frontend profile component to an existing project directory.

subdir and package_manager default to the selected profile’s defaults. watch_paths are the inputs outside the subdir that also run the component’s CI (default default_npm_watch_paths() of pkg_dir). Returns the wads.templating.GenerationResult.

>>> import tempfile
>>> d = tempfile.mkdtemp()
>>> res = apply_frontend(d, profile="ts", project_name="widget")
>>> sorted(res.added)
['.github/workflows/npm-ci-ts.yml', 'ts/package.json', 'ts/src/index.test.ts',
 'ts/src/index.ts', 'ts/tsconfig.json', 'ts/tsconfig.test.json']
Return type:

GenerationResult

wads.profiles.apply_native(pkg_dir, *, backend='maturin', project_name, license=None, overwrite=(), generate_lockfile=True, lockfile_timeout=300, on_add=None, on_skip=None, on_error=None, on_attention=<function _warn_attention>)[source]¶

Scaffold a native core (backend) into the project at pkg_dir.

Writes the backend’s template files that do not exist yet (overwrite names the ones to replace). A missing or blank facade (__init__.py) is written; a real one is kept, the files of a new package only (py.typed) are left out, and the lines the template’s tests need are reported. on_attention(filename, reason) also gets missing .gitignore entries and a lockfile it could not generate. pyproject.toml is not touched here: populate merges native_pyproject_fragment() into a new one and reports native_pyproject_todo() for an existing one.

>>> import tempfile
>>> d = tempfile.mkdtemp()
>>> res = apply_native(
...     d, project_name="fast_thing", generate_lockfile=False, on_attention=None
... )
>>> [t for t in res.added if t.startswith("rust/")]
['rust/core/Cargo.toml', 'rust/core/src/lib.rs', 'rust/py/Cargo.toml',
 'rust/py/src/lib.rs']
Return type:

GenerationResult

wads.profiles.native_licence(pkg_dir)[source]¶

The SPDX expression the package at pkg_dir declares, or None.

Metadata only, never a guess from a licence document: [project].license as a string or {text = ...}, canonicalised; else the License :: classifiers, joined with OR (None if any is not recognised). {file = ...} or license-files alone say no SPDX id, so None.

>>> import tempfile
>>> d = tempfile.mkdtemp()
>>> native_licence(d) is None
True
>>> _ = open(os.path.join(d, "pyproject.toml"), "w").write(
...     '[project]\nclassifiers = ["License :: OSI Approved :: MIT License",'
...     ' "License :: OSI Approved :: Apache Software License"]\n'
... )
>>> native_licence(d)
'MIT OR Apache-2.0'
Return type:

Optional[str]

wads.profiles.native_names(project_name, *, license=None, backend='maturin')[source]¶

Map the template tokens to their values for project_name.

The project name is the import name (populate makes <name>/<name>/), so it must be a lowercase identifier; Cargo package names are its kebab-case form. license is the package’s SPDX id; without one the crates declare no licence (the profile’s unlicensed edits) rather than a guessed one.

>>> native_names("fast_thing", license="Apache-2.0")
{'tmpl_pkg': 'fast_thing', 'tmpl-pkg': 'fast-thing', 'tmpl-license': 'Apache-2.0'}
>>> native_names("fast_thing")['license = "tmpl-license"']
'# license = "<SPDX id>"'

dict

wads.profiles.native_pyproject_gaps(pyproject, project_name, *, backend='maturin')[source]¶

(required, recommended): what an EXISTING pyproject lacks for backend.

Required: absent keys and missing list items, and a replaces table whose scalars differ (another build backend) or are absent, given whole. Recommended: values set otherwise than the template’s (a deliberate choice stays yours), and a replaces table that only lacks list items (e.g. an older requires pin).

>>> required, recommended = native_pyproject_gaps(
...     {"build-system": {"requires": ["maturin>=1.9.4,<2"], "build-backend": "maturin"}},
...     "fast_thing",
... )
>>> "build-system" in required, recommended["build-system"]["build-backend"]
(False, 'maturin')
Return type:

tuple

wads.profiles.native_pyproject_todo(pyproject, project_name, *, backend='maturin')[source]¶

What an EXISTING pyproject needs for backend, as TOML text (’’ if nothing).

populate never rewrites an existing pyproject.toml; it reports this instead. Two blocks, each valid TOML: # Required and # Recommended (native_pyproject_gaps()).

>>> print(native_pyproject_todo({}, "fast_thing"))
# Required: merge into pyproject.toml (lists: add the items shown).
# [build-system] replaces yours.
[build-system]
requires = [...]
build-backend = "maturin"
...
module-name = "fast_thing._core"
...
>>> pyproject = merge_native_pyproject({}, native_pyproject_fragment("fast_thing"))
>>> native_pyproject_todo(pyproject, "fast_thing")
''

str
